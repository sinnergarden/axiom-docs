# M2 研究评估 SOP（讨论稿）

每轮策略 proposal 只写 idea 和实现选择。本页统一规定评估流程；已看过的历史不能重新命名为未触碰测试集。

## 1. 固定比较条件

运行前记录假设、对照、特征、训练标签、评价标签、历史成员池、时间切分、交易与费用配置。主比较使用共同有效样本，同时报告各方案原生覆盖，避免靠删掉困难样本取得改善。不同训练目标的预测可比较，但评价目标和样本必须一致。

## 2. 信号报告

统一输出整体及分年IC/Rank IC、头部10%表现、覆盖率、行业/规模暴露，以及关键特征家族消融。低频或重叠标签按时间块估计不确定性；每20日抽样的60日标签仍然重叠。选特征仅使用开发/训练验证资料，保留段只用于已冻结候选的确认。

## 3. 账户报告

使用同一份保存的样本外信号，输出50万元账户的CAGR、最大回撤、Sharpe/Calmar、换手、费用和成交比例。检查Top5个股与年份贡献；未成交样本及原因保留。诊断分组收益不能当账户净值。

## 4. 稳健性与决策

有希望的候选再检查延迟入场、较慢调仓和成本压力。固定信号即可完成这些比较，不能重训模型挑最好曲线。记录全部尝试，结论为继续、修改或停止，并说明最关键证据及剩余风险。缺数据、程序错误和投资假设失败分别处理。

## 5. 前向验证

冻结候选后进入独立shadow，使用与回测相同的决策和账户规则。研究结果本身不授权实盘。25% CAGR、25%最大回撤、Sharpe约1–1.2是最终策略/组合目标，不能倒推为反复试验必须得到的数字。

## 结果复用

保存预测后，换评价标签、信号组合或交易规则复用已有预测；换模型或训练标签才承担必要训练。每轮同时记录首次准备、复用后训练、评价和回测耗时。

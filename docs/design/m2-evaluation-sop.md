# M2 研究评估 SOP（讨论稿）

每轮策略 proposal 只写 idea 和实现选择。本页统一规定评估流程；已看过的历史不能重新命名为未触碰测试集。

## 1. 固定比较条件

运行前记录假设、对照、特征、训练标签、评价标签、历史成员池、时间切分、交易与费用配置。主比较使用共同有效样本，同时报告各方案原生覆盖，避免靠删掉困难样本取得改善。不同训练目标的预测可比较，但评价目标和样本必须一致。

首轮评价期限提议为20/40/60/120/180个交易日，40日是A01主目标，其余用于观察信号持续性。所有期限统一从信号日后第1个交易日开盘计至第H个交易日收盘，并保持总回报、复权和单位口径一致。各期限只使用已经成熟的标签；同一期限的所有候选使用相同评价日期与股票交集。跨期限比较衰减时另取共同成熟日期，避免长标签缺少尾部样本造成错觉。

报告以“候选信号×评价期限”排列，同一列可比较不同模型、训练标签及组合信号。例如60日预测与180日预测都对照180日真实收益；不能拿各自不同标签的IC直接选赢家。新增评价期限复用预测，仅新增训练目标时才训练新模型。

## 2. 信号报告

统一输出整体及分年IC/Rank IC、头部10%表现、覆盖率、行业/规模暴露，以及关键特征家族消融。低频或重叠标签按时间块估计不确定性；每20日抽样的60日标签仍然重叠。选特征仅使用开发/训练验证资料，保留段只用于已冻结候选的确认。

主指标为每日截面Rank IC的等权均值，辅以Pearson IC、十组收益单调性、头部10%相对股票池表现及Top5集中度。固定相关系数、并列排名、最小有效样本和缺失处理实现，报告有效日期数；ICIR明确计算口径，不把重叠标签当独立样本套用简单年化。比较改善时使用同日期配对差值及时间块不确定性，区块长度至少覆盖评价期限，并检查相邻长度的敏感性。

进入策略研究的依据：样本外主指标和头部分组具有同向支持，优势在多个时间段可见，去掉最大贡献年份后不完全消失，并说明行业和规模暴露的贡献。没有跨期限通用的IC硬门槛；证据不足列为待观察。家族消融限1–2轮，用于检验假设，不能按全历史结果逐列筛到最好。

## 3. 账户报告

使用同一份保存的样本外信号，输出50万元账户的CAGR、最大回撤、Sharpe/Calmar、换手、费用和成交比例。检查Top5个股与年份贡献；未成交样本及原因保留。诊断分组收益不能当账户净值。

候选之间固定日期、初始资金、费用、滑点、可交易规则及风险统计口径；并列展示同期间ETF轮动基线和对应股票池指数。收益统计使用实际账户日净值；换手和成交统计来自委托/成交。用实际持有期分布、不同持有期收益和卖出后的信号表现，判断预测期限能否被交易规则兑现。

## 4. 稳健性与决策

有希望的候选再检查延迟入场、较慢调仓和成本压力。固定信号即可完成这些比较，不能重训模型挑最好曲线。记录全部尝试，结论为继续、修改或停止，并说明最关键证据及剩余风险。缺数据、程序错误和投资假设失败分别处理。

每个idea开跑前列出最多5版有明确区别的策略方案。继续的依据是净收益/回撤权衡改善、集中度风险可解释，且提高交易成本或稍延迟执行后优势仍有保留。信号改善而账户变差，先检查换手、成交、持有期与集中度；信号未改善，先检查投资假设及特征。PIT、成熟或成交正确性失败的结果暂不参与策略优劣判断。

## 5. 前向验证

冻结候选后进入独立shadow，使用与回测相同的决策和账户规则。研究结果本身不授权实盘。25% CAGR、25%最大回撤、Sharpe约1–1.2是最终策略/组合目标，不能倒推为反复试验必须得到的数字。

## 结果复用

保存预测后，换评价标签、信号组合或交易规则复用已有预测；换模型或训练标签才承担必要训练。每轮同时记录首次准备、复用后训练、评价和回测耗时。

分层保存预测、信号分析及账户结果，可参考[Qlib Record Templates](https://qlib.readthedocs.io/en/stable/component/recorder.html#record-template)。上述期限与晋级标准是Axiom本轮研究提案，执行前与具体实验配置一起冻结。

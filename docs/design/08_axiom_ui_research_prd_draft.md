# Axiom 研究工作台 PRD 草案

2026-10-04 · 待讨论。本文提出功能、流程和验收候选，尚未冻结产品要求、指标口径或接口，也不表示功能已经实现。全部图例为合成示意，不能作为实际回测或收益证据。

**已确认的工作原则：**讨论清楚 → 写入 axiom-docs → 其他 repo/task 引用 → 开发 → 对照验收。设计变更先更新文档，不先实现再补事实。设计源、图源和确认后的口径统一保存；聊天用于讨论，HTML 和 ZIP 是生成交付。本文引用[现有 UI 设计](06_axiom_ui.md)的只读与上下文要求；模块分工只引用第 7 节的总纲边界表。六组功能、指标候选和 A/B 布局仍待讨论。

## 1 目标用户与研究问题

目标用户是与 dot 一起研究策略的个人研究者。用户提出 idea，dot 在另行授权的任务中实现并检查；工作台让用户看懂已保存结果，决定保留、否定或修改假设。首版围绕一个实验及其相关运行，避免先做完整研究平台。

用户需要回答：这轮检验什么、改了什么；相对基准和旧版是否改善；收益与风险集中在哪里；为什么在某日买卖或没有成交；证据是否来自同一批固定输入；下一轮只改什么。成功标准是用户能从结果指出证据和下一步，而非曲线达到收益目标。

## 2 从 idea 到下一轮的用户流程

| 步骤 | 用户操作 | 页面给出的结果 |
|---|---|---|
| idea | 与 dot 明确假设、对照和拟改因素 | Research 保存实验说明；UI 读取已有记录，不启动计算 |
| 实验列表 | 按假设、版本或状态找实验，选择已保存运行 | 看见成功、失败、阻断和负结果；不会只列赢家 |
| 单次回测 | 打开一个运行 | 上下文固定；先看收益风险与主要限制，再下钻细节 |
| 版本及基准比较 | 选旧版或基准作为对照 | 展示 Research 提供的两版变动清单和对应保存结果，注明可比较范围 |
| 变动与结果复盘 | 选变动项、异常日、月份、持仓段或成交点 | 并列查看变动清单与结果，定位证券、日期及交易链；UI 不生成因果结论 |
| 下一轮 | 复制本轮上下文、证据位置与拟改因素 | 得到可交给 dot 讨论的摘要；新实验仍由 Research 任务创建，UI 不重跑 |

所有视图保留同一实验、运行和版本上下文。返回总览不重置选择；显式换运行后图表和侧栏一起切换。F01 图展示实验与版本的关系。

## 3 六组功能提案

### F01 实验说明与版本

- **输入与展示：**Research 保存的假设、参数、输入输出版本、运行关联、版本差异、样本范围与限制。列表显示状态与版本；详情展示本轮改动及对照对象。
- **操作与结果：**筛选、选实验、打开运行、查看两版改动，得到对应结果及变动清单；复制摘要用于下一轮讨论。
- **缺失与 owner：**未保存的说明显示“未提供”，不由 UI 从参数编造假设。Research 提供实验记录、关联及版本变动清单；UI 负责选择与导航。**验收候选：**包含正、负、失败和阻断样例；切换后全部面板指向同一运行，原记录不变。

![F01 实验列表与版本关系，合成示意](ui-prd-assets/figure01_experiment_versions.svg)

### F02 同口径比较

- **输入与展示：**所选 A/B 运行、Research 保存的版本变动清单及 Engine 保存的基准、比较结果和口径。并列展示变动项、净值及指标差异，注明期间、费用、分红和执行假设是否可比。
- **操作与结果：**选择对照、开关曲线、点日期，得到同日原值和差异；多个轴变化时标为整体对照，不给因果结论。
- **缺失与 owner：**未保存基准则不画基准线；口径不兼容时提示具体差异，不静默裁剪或重算。Engine 提供账户评估及基准；Research 提供版本变动清单并关联运行结果；UI 负责选择、比较展示及联动。**验收候选：**兼容样例逐点等于保存值，不兼容样例不会被标成同口径。

![F02 策略与候选基准比较，合成示意](ui-prd-assets/figure02_comparison.svg)

### F03 收益与风险

- **输入与展示：**Engine 保存的净值、标准指标及回撤序列。总览显示期间收益、最大回撤、费用、成交额与净值；风险区与净值共用时间轴。
- **操作与结果：**悬停看日期及原值，选择异常区间，跳转该区间复盘。筛选仅定位；区间指标若未保存，不在前端另算。
- **缺失与 owner：**缺指标或序列时分别显示不可用，不补零；短样本不补年化或 Sharpe。Engine 定义和计算，UI 格式化。**验收候选：**数值、符号和单位与 owner 相等；严格阻断的零成交运行及日线近似运行有明确身份，处理完成不代表策略有效。

![F03 净值与回撤路径，合成示意](ui-prd-assets/figure03_return_risk.svg)

### F04 K 线与交易复盘

- **输入与展示：**绑定该运行的 Data OHLC、成交量及 Engine 保存的持仓、决策、委托、成交。价格图叠加成交点和持仓区间；侧栏分开信号日、决策日与成交日。
- **操作与结果：**选择证券、日期或 B/S 点，侧栏显示原价量、费用、信号依据和执行原因；选择未成交记录可看阻断原因。图层开关不换数据版本。
- **缺失与 owner：**缺 high/low 就提示 K 线不可用，可展示明确命名的现有价格线；缺 trace 显示未保存，不编造理由。Data 提供固定行情，Research 提供保存信号，Engine 提供交易链。**验收候选：**点值可逐键对应原记录；意图、拒单和部分成交不会被画成同一种成交点；复权坐标不能改写原成交价。

![F04 价格与交易复盘，合成示意](ui-prd-assets/figure04_trade_replay.svg)

### F05 盈亏与月度统计

- **输入与展示：**Engine 保存的月收益、闭合持仓段及统计口径。显示月度收益、持仓段净盈亏分布和胜率分母；未闭合段单列。
- **操作与结果：**点月份或持仓段，定位对应净值区间和交易链；用同一上下文查看收益是否集中于少数月份或少数持仓段。
- **缺失与 owner：**未保存汇总就显示不可用，不把成交笔数当完整交易数。Engine 提供费用及分红归属、持仓段和统计；UI 不重做核算。**验收候选：**正负柱共用零轴，分子、分母、平局和开放段可见；点击关联准确，期末开放段不混入闭合段统计。

![F05 月度收益与闭合持仓段盈亏，合成示意](ui-prd-assets/figure05_monthly_segments.svg)

### F06 结果追溯

- **输入与展示：**owner 保存的依赖、版本、质量说明、运行状态和账户水位。主要限制用短句留在主视图；完整来源及引用折叠在追溯区。
- **操作与结果：**展开某项、从图中点查、复制上下文摘要，得到对应来源与保存证据；运行状态、数据缺证和执行近似分别解释。
- **缺失与 owner：**来源不可读时保留已知身份并报缺口；校验失败阻止当作有效结果展示，旧缓存注明截止点。各 owner 提供自身证据，UI 组合只读投影。**验收候选：**切换/刷新不混旧侧栏，现金与持仓水位一致；浏览前后 owner 产物不变，无采集、训练、重跑或下单调用。

![F06 折叠的依赖与证据链，合成示意](ui-prd-assets/figure06_provenance.svg)

## 4 留给用户的三项讨论

以下为推荐讨论方案，不是已确认默认值。确认后由相应 owner 保存定义及标准结果，UI 只读展示。

| 讨论项 | 推荐方案 | 确认后的影响 |
|---|---|---|
| 首版功能优先级 | 先完整看懂一次运行：实验说明、收益风险、交易复盘、基本追溯；随后补同口径比较及盈亏统计 | 若比较或统计更优先，先补对应 owner 结果，再调整实施顺序 |
| 本例基准选择 | ETF 轮动的主对照推荐固定七 ETF 在评估起点等权买入持有，不持续再平衡；旧策略作为版本对照 | 推荐只针对这个 ETF 轮动实验，不推广为所有策略的统一基准；当前基准线只是合成示意 |
| 完整持仓段统计 | 单证券持仓 0→非0→0 为一个完整段，段内加减仓合并，费用及分红计入净盈亏；净盈利段数÷全部闭合段数，平局保留，开放段单列且排除在分母外 | 确认后 Engine 输出标准段报告；UI 明示分子、分母与开放段，不把一次成交当完整交易 |

其余工程一致性由我们负责：比较时核对期间、初始账户、价格、费用、分红与执行假设；不兼容时列出差异。收益、回撤和月收益读取 Engine 标准结果，缺价、首尾不完整月及未保存指标明确标注；短样本不补年化。复盘展示变动清单和保存链，不把相关性写成信号因果。以上按 owner 定义实现和验收，不额外变成用户选择题。

## 5 首版 后续与非目标

**首版候选：**一条完整只读路径，覆盖实验列表、单次运行、六组功能入口及一致的缺失行为。先连接已有结果，再接 owner 补齐的比较和统计；缺失入口不能冒充完整功能。A/B 是同一组功能的布局候选，先讨论功能，再确定布局。

**迭代顺序候选：**①讨论本稿和指标口径；②owner 补实验关联、固定行情及标准评估投影，用小样本核对；③实现总览、选择及交易下钻；④接同口径比较、月度与闭合段统计；⑤联动和只读验收后，再讨论部署。若用户优先比较，应调整第③④步顺序，而非由 UI 补算缺少指标。

**后续候选：**更多实验筛选、多期/多模型图层、阶段稳健性和大范围分页。**非目标：**采集、训练、自动研究、后台回测计算、改账本、真实下单、自动发布，以及软件承诺 alpha 或长期收益。

## 6 当前已有与接口缺口

截至本稿引用的[当前交付](../current-delivery.md)，真实固定 ETF 样本已保存净值、持仓、决策/委托/成交、六项运行汇总及来源版本；现有 UI 能生成只读静态结果报告，尚不是本 PRD 的交互产品。

待 owner 对齐的内容包括：Research 的实验列表、说明及版本关联投影；Engine 的同口径基准、逐日回撤、月度与完整闭合段报告；Data 绑定该运行的完整 OHLC 展示投影。当前 Engine 保存的行情只有 open/close/volume，这不代表 Data 没有 high/low。这些缺口仅记录需求，不在本稿发明另一套合同或假称接口已完成。

## 7 边界与未来部署约束

模块职责、输入、输出、消费者与不负责范围统一引用[总纲唯一模块边界表](01_axiom_overview.md#module-boundaries)。本 PRD 的功能输入与验收说明仅应用该分工，不另维护一份边界规范，也不新增接口或计算职责。

**已确认的部署方向，尚未授权执行：**后台计算与存储在用户回测云；前端优先 Sites，若公开资格不支持则用 GitHub Pages 平台域名，无自有域名也可。第一版只读保存产物；后续再接 HTTPS 只读 API 和鉴权，密钥不放前端。公开 demo 与私有研究隔离，公开示例不携带私有结果。

具体读取通道、鉴权和托管配置仍待讨论。本稿不确认 Sites 公开资格，也没有实际部署、付费服务或公开研究数据的授权。
